Правила использования

Настоящие Правила регулируют использование сервиса SkrepNet (далее — «Сервис»).

1. Общие положения

  • Сервис предоставляется бесплатно для личного некоммерческого использования.
  • Используя Сервис, вы соглашаетесь с настоящими Правилами.
  • Сервис не является средством для обхода закона.

2. Что запрещено

  • Использование Сервиса в противоправных целях.
  • Распространение вредоносного ПО, спама, CSAM, материалов экстремистского характера.
  • Попытки взлома, DDoS-атаки, сканирование чужих сетей.
  • Передача доступа третьим лицам (кроме личных устройств).
  • Использование более 3 IP-адресов одновременно.

3. Ограничения

  • Один пользователь — одна подписка.
  • Лимит: 3 IP одновременно.
  • Срок подписки: 30 дней с возможностью продления.

4. Ответственность

  • Пользователь несёт полную ответственность за свои действия в сети.
  • Администрация не несёт ответственности за возможные сбои, перебои или ущерб.
  • При нарушении правил доступ может быть заблокирован без предупреждения.

5. Изменения

Правила могут быть изменены. Актуальная версия всегда доступна по этому адресу.
