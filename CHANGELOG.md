# Changelog

Все значимые изменения проекта SkrepNet Bot.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
С версии v1.5 версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [Unreleased]

### Добавлено
- Комментарии к клиентам в 3x-ui (Telegram ID, username, источник: bot / ref / web / manual)
- Диалог выбора комментария при одобрении заявки (ввод вручную или авто)
- Обработка конфликта email: использовать существующий / суффиксы (_2, _3) / Telegram ID / ручной ввод
- Список заявок с кнопками выбора и карточкой пользователя
- Админ-списки пользователей с пагинацией (продление, удаление, сброс)
- Сортировка списка: сначала кириллица по алфавиту, потом латиница
- Подменю «👥 Пользователи» в «🛠 Управление»
- Автоматическое обновление меню при продлении подписки

### Изменено
- Кнопка техподдержки: «🆘 Поддержка» → «🆘 Техподдержка» (совпадение с обработчиком)
- Формат в списках: `@username — Имя` вместо `Имя — ID`
- Компактное меню «🛠 Управление» (2 кнопки в ряд)
- Формат комментария в 3x-ui: `{текст админа} | TG: {id} @{username}` или `TG: {id} @{username} | {источник}`

### Удалено
- Кнопки и обработчики добавления/удаления админов через бота
- Функция `admin_list` (список админов)
- Состояния `waiting_add_admin`, `waiting_del_admin`
- Старый `install.sh` (заменён на `scripts/`)
- Мёртвый код `INBOUND_LV` из `config.py`

### Исправлено
- `get_client` в `xui_client.py` — корректно разворачивает структуру ответа 3x-ui (`obj.client.subId`)
- Дубликаты функций в `handlers/admin.py`
- Кнопка «🆘 Техподдержка» не работала (текст не совпадал с обработчиком)
- Заменён MD5 на SHA-256 для генерации subId (CodeQL)

### Безопасность
- Обновлён `python-dotenv` до 1.2.2 (исправлена CVE)
- Включены: Dependabot, CodeQL, Secret scanning
- Добавлен `SECURITY.md`

### Планируется
- Лимит на количество пользователей (MAX_USERS в .env)
- Второй сервер (🇱🇻) в подписке
- Онлайн-клиенты (кто сейчас подключён)
- Мониторинг панели 3x-ui (CPU/RAM/трафик)
- Статистика донатов через API
- Инструкции для Apple TV, Samsung TV, LG TV

## [1.4] — 2026-10-08

### Добавлено
- Соглашение с пользователем (3 документа на telegra.ph)
- Меню «Управление» для админов (всё на кнопках)
- Добавление/удаление админов по username
- Обновление подписок по username
- Удаление пользователей (из БД и 3x-ui одновременно)
- Рассылка всем активным
- Статистика + топ-5 приглашающих
- Кнопка входа в панель 3x-ui
- История обновлений бота

### Изменено
- Handlers разбиты на модули: start, subscription, donate, connect, admin, changelog, invite

## [1.3] — 2026-10-07

### Добавлено
- Донат через Telegram Stars (10, 25, 50, 100 звёзд)
- Инструкции для 6 платформ: Android, iOS, Windows, macOS, Android TV, Linux
- Happ — основное рекомендуемое приложение
- Отдельные инструкции для Android TV
- Linux-сборки Happ (.deb, .rpm, .AppImage)
- Защита от спама при заявке (по статусу pending)
- Автоудаление неактивных пользователей (30+ дней)
- Кастомная страница подписки с автообновлением

## [1.2] — 2026-10-07

### Добавлено
- Админ-команда `/stats`
- Реферальная система с кнопкой «Поделиться»
- Плашка доната при каждом взаимодействии
- Напоминания за 3 дня и в день окончания (тихие)
- Ежедневные бэкапы базы (в 3:00, хранение 30 дней)
- Systemd-автозапуск (бот сам поднимается после падения)
- Логирование уведомлений админам
- Второй админ получает уведомления
