# Changelog

Все значимые изменения проекта SkrepNet Bot.
Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/).
С версии v1.5 версии следуют [Semantic Versioning](https://semver.org/lang/ru/).

## [1.5] — 2026-10-10

### Добавлено
- Скрипты установки разделены: `scripts/install-bot.sh` и `scripts/install-web.sh`
- Проверка доступности 3x-ui после ввода настроек (с таймаутом curl)
- Проверка порта 80 перед certbot в `install-web.sh`
- Прогресс установки зависимостей (pip без `-q`)
- Компактный финальный вывод с командами

### Изменено
- README обновлён: инструкция ссылается на `scripts/`
- Убраны блоки кода из README (устранены проблемы с копированием)
- `.gitignore` дополнен: `*.log`, `*.pyo`, `venv-web/`

### Удалено
- Мёртвый код: `INBOUND_LV` из `config.py` (не использовался)
- Старый `install.sh` из корня (заменён на `scripts/`)
- Рамки `═══` и функция `line()` из скриптов
- `clear` из скриптов (история экрана сохраняется)

## [1.4] — 2026-10-08

### Добавлено
- Соглашение с пользователем (3 документа на telegra.ph)
- Меню «Управление» для админов (всё на кнопках)
- Добавление/удаление админов по username
- Обновление подписок по username
- Удаление пользователей (из БД и 3x-ui одновременно)
- Рассылка всем активным
- Статистика + топ-5 приглашающих
- Кнопка входа в панель 3x-ui
- История обновлений бота

### Изменено
- Handlers разбиты на модули: start, subscription, donate, connect, admin, changelog, invite

## [1.3] — 2026-10-07

### Добавлено
- Донат через Telegram Stars (10, 25, 50, 100 звёзд)
- Инструкции для 6 платформ: Android, iOS, Windows, macOS, Android TV, Linux
- Happ — основное рекомендуемое приложение
- Отдельные инструкции для Android TV
- Linux-сборки Happ (.deb, .rpm, .AppImage)
- Защита от спама при заявке (по статусу pending)
- Автоудаление неактивных пользователей (30+ дней)
- Кастомная страница подписки с автообновлением

## [1.2] — 2026-10-07

### Добавлено
- Админ-команда `/stats`
- Реферальная система с кнопкой «Поделиться»
- Плашка доната при каждом взаимодействии
- Напоминания за 3 дня и в день окончания (тихие)
- Ежедневные бэкапы базы (в 3:00, хранение 30 дней)
- Systemd-автозапуск (бот сам поднимается после падения)
- Логирование уведомлений админам
- Второй админ получает уведомления

## [1.1] — 2026-10-07

### Изменено
- Бот перенесён на зарубежный сервер (нет блокировок Telegram)
- API-токен 3x-ui (Bearer) вместо логина по паролю
- Генерация subId вручную (обход бага 3x-ui)
- Продление подписки по кнопке (без автопродления)
- Ссылка на подписку через встроенную систему 3x-ui

## [1.0] — 2026-10-07

### Добавлено
- Первая версия бота
- Выдача подписок Hysteria2
- Одобрение админом при первой заявке
- Лимит 3 IP одновременно
- Срок подписки — 30 дней
